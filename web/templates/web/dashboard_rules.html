Rule · High

When a low-privilege user moves laterally too fast.

Flags credentials used on more than three new endpoints in a short window, especially across different segments. Treats lateral movement as a story, not a single event.

Attached to: internal workstations · Simulated design rule.

Rule · Medium

When office tools spawn shells in the dark.

Surfaces office processes spawning command interpreters outside normal business hours, or from unusual hosts. Keeps the language human-first.

Attached to: laptops · Mixed platforms · Design-only behaviour.

Rule · Low

When endpoints repeatedly knock on closed doors.

Highlights repeated denied outbound connections to rare destinations, starting as a low-level rule that can be tuned later.

Attached to: gateways and edge nodes · Sample only.

How this page should evolve

A bridge between human language and detection logic.

  • Each rule is written as a sentence so analysts can understand the intent before seeing the query syntax.
  • Later, each card can link to a full rule detail view: query, fields, attached alerts, and change history.
  • The catalogue can be filtered by level, platform, environment, or owner without redesigning the layout.
  • In this static phase, everything is sample data only – no engine is running underneath yet.
