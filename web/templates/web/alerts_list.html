How to read this table

This is a design-only snapshot of how alerts might look.

  • Each alert is expressed as a short sentence instead of a raw log line.
  • The level column is meant to signal how “loud” the alert should feel to a human.
  • Endpoint, rule, and summary are aligned so you can scan by any of them without friction.
  • In a live system, you would be able to pivot from each row into a deeper investigation view.
